# Журнал обновления шаблона nx_template

Ветка: `nx_template_2026` (от `master`, 310781e). Журнал ведётся по ходу работы: сюда записываются решения, сделанные правки, отложенные пункты и открытые вопросы. Если обсуждение потеряно, состояние восстанавливается по этому файлу и истории коммитов.

Цель: технологически освежить шаблон для новых проектов, не переделывая его. Классы и атрибуты, которыми пользуются в вёрстке (`.tab`, `.tab_opened`, `.nx-tabs`, `.nx-select`, `.with_big`, `.hyphenate`, `.to-nx-nav`, `.to-social-nav`, `nx-flex-*`), сохраняются.

Принцип работы: ничего не удаляем только потому, что в шаблоне это не используется — шаблон должен оставаться совместимым с компонентами проектов. Каждую замену сначала проверяем по контексту, истории git и в браузере, и только потом предлагаем.

## Следующие этапы

1. **Безопасное обновление.** Внешне ничего не меняется.
   - jQuery 3.6.3 → 3.7.1, Migrate 3.4.0 → 3.6.0 (1.4.1 остаётся), jQuery UI 1.13.2 → 1.13.3.
   - Вендорные префиксы в нашем CSS: в `styles.css` нужно 13 из 155, в `template_styles.css` — 8 из 98 (по Autoprefixer и `.browserslistrc`). Блок jQuery UI внутри `styles.css` и чужие библиотеки не трогаем.
   - Подключить `nx.woff2` первым в `@font-face`, добавить `font-display`.
   - Запасные значения для `clamp()` (исключение из стека).
   - Убрать мёртвое для IE: `X-UA-Compatible`, условные комментарии.
2. **Доступность** — см. «Отложено».
3. **Возможности, которыми стоит начать пользоваться.** Найдено при разборе шаблона и stalker-tool.ru, 01.10.2026:
   - CSS Grid для сеток: на stalker-tool.ru нет ни одного `display: grid`, зато 11 отрицательных отступов с `calc(100% + …)`, 26 `calc(100% - …)`, 19 `float`. `gap` в grid безопасен даже на уровне 3;
   - заливка во всю ширину вместо псевдоэлементов по 3170 px: `box-shadow: 0 0 0 100vmax …; clip-path: inset(0 -100vmax)`;
   - `aspect-ratio` вместо хаков `padding-top: %` (на уровне 2 нужен запасной вариант);
   - атрибуты полей: `inputmode`, `autocomplete`, `type="tel" / "email" / "search"`, `enterkeyhint`;
   - `width` и `height` у картинок, `<picture>` с WebP, `decoding="async"`, `preconnect`, `content-visibility`;
   - `IntersectionObserver` вместо обработчиков `scroll`, `matchMedia` вместо `resize`, `scrollTo({behavior: 'smooth'})`;
   - год в копирайте — на сервере (`<?=date('Y')?>`), `Intl.NumberFormat` и `Intl.PluralRules` для цен и склонений, `<template>` вместо Mustache.
